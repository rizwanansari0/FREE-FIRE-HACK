# SHADOW RADAR PRO - Android Offline Radar Simulator

## Overview

SHADOW RADAR PRO is a professional offline Android radar simulator and training utility.
It runs entirely on-device without internet access, no root required, and contains no code
injection, memory modification, or anti-cheat bypass functionality.

**Features:**
- Professional dark gaming UI with neon green/red accents
- Animated radar with rotating sweep and concentric rings
- Simulated target generation (4, 8, or 12 targets)
- Real-time FPS counter
- Radar ON/OFF toggle
- Crosshair ON/OFF toggle
- Sound effects toggle
- Settings persistence via SharedPreferences
- Responsive layout for all screen sizes
- Battery-efficient pause/resume handling
